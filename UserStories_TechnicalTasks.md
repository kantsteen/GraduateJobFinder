# User stories

Som bruger  
Vil jeg kunne klikke på et jobopslag  
Så jeg kan læse indholdet i opslaget

Som bruger  
Vil jeg kunne søge efter jobpslag  
Så jeg nemt kan finde et jobopslag jeg leder efter

Som bruger  
Vil jeg kunne filtrere jobopslag baseret på programmeringssprog  
Så jeg nemt kan finde en stilling der passer til mine evner

Som bruger  
Vil jeg kunne sortere jobopslag ud fra opslagsdato  
Så jeg nemt kan se de nyeste jobopslag

Som bruger  
Vil jeg kunne filtrere jobopslag fra som er X antal mk væk fra en valgt adresse  
Så jeg nemt kan finde job nær mig

Som bruger  
Vil jeg kunne filtrere for ansættelsestype  
Så jeg nemt kan finde jobopslag som passer til mig (fastansættelse, freelance, praktikplads osv.)

Som bruger   
Vil jeg kunne filtrere for arbejdstid 
Så jeg nemt kan finde jobopslag som passer til mig (fuldtid, deltid)
